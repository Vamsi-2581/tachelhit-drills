# iOS build — what is done, what still needs a Mac

Phase P6 of `../docs/IOS_FIX_PLAN.md`. Phases P1–P5 live in the shared code and
already run on web and Android; nothing here changes them.

## Done from Windows (committed on this branch)
- `ios/` Xcode project generated with **CocoaPods** (`npx cap add ios --packagemanager CocoaPods`).
  Capacitor 8 defaults to Swift Package Manager, but `capacitor-voice-recorder` and
  `@capacitor-community/speech-recognition` ship only CocoaPods specs — the Podfile lists all 8 plugins.
- `ios/App/App/Info.plist`: the five usage strings (microphone, camera, photo library read + add,
  speech recognition, all in Catalan), `ITSAppUsesNonExemptEncryption = NO`, development region `ca`,
  iPhone locked to portrait (same as Android).
- App icons + splash for both platforms, generated by `npm run cap:assets` from `resources/`
  (placeholder: Tifinagh ⵣ on brand blue #2E4B8C). Replace the PNGs in `resources/` and re-run to rebrand.
- `.github/workflows/mobile.yml`: on every push to `main`/`feature/**` touching `frontend/`, GitHub
  builds the **Android debug APK** (ubuntu) and compiles the **iOS app for the Simulator** on a free
  `macos-15` runner (the repo is public). Both are downloadable artifacts of the run.
  This is the iOS compile check — no Mac needed to know the project builds.
- `capacitor.config.ts`: `ios.contentInset = 'never'` + safe-area padding in the app, Keyboard
  `resize: 'native'`; inline playback flags on every player; recordings named by real MIME type
  (iOS → `.m4a`/`.mp4`); downloads via the native share sheet; identity token mirrored to the native store;
  cold-start banner while the Render backend wakes up.

## Needs a Mac (or a signed CI lane)
### 0. Prerequisites
macOS with Xcode 16+, CocoaPods (`brew install cocoapods`), Node 22+, an Apple Developer team (TestFlight is paid).

### 1. First run
```sh
cd frontend && npm install
npm run cap:ios          # = build + cap sync ios (runs pod install) + open Xcode
```
In Xcode: Signing & Capabilities → pick the team; bundle id is `com.tachelhit.app`.
Commit the generated `ios/App/Podfile.lock`.

### 2. Must be tested on a real device
1. **YouTube embeds** from the `capacitor://localhost` origin (Reels, drill videos, video library).
   If YouTube answers "Error 153", host `public/yt.html` on the Vercel site and iframe it with
   `origin=https://tachelhit-drills.vercel.app`.
2. Microphone prompt on the first "Veu" tap in Nou drill; the recording saves and plays back;
   the pronunciation check returns a score.
3. Share sheet on "Descarrega el Short".
4. Keyboard does not cover the copilot input or the editor's bottom bar.
5. Status bar / Dynamic Island never overlaps the sticky nav or the player header.

### 3. Release
Xcode → Product → Archive → Distribute → TestFlight. To automate, extend `mobile.yml` with a signed
job (Fastlane `match`, certificates in repo secrets — never in the repo).

## Android (same branch)
`npm run cap:android` opens Android Studio. A debug APK is also built by `mobile.yml` on every push;
install it with `adb install app-debug.apk`. Release signing (keystore) is still to be set up.
